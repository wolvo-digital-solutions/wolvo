# WOLVO — DESIGN SYSTEM

## Brand personality

WOLVO should communicate:
- intelligence
- precision
- creativity
- modern technology
- confidence
- forward motion

## Color system

Primary background:
`#030B1E`

Supporting background:
`#06132D`

Reference blue range:
`#0935CA`
`#0D79FD`
`#18ACFD`
`#1FCBFD`

Text:
`#F7FAFF`

Muted:
`#9AA8BD`

Border:
`#16345E`

Important:
The original uploaded logo remains the ultimate color reference.

## Typography

Heading:
Space Grotesk

Body:
Inter or Manrope

Recommended hierarchy:

H1:
clamp(3rem, 8vw, 8rem)

H2:
clamp(2rem, 5vw, 5rem)

H3:
clamp(1.5rem, 3vw, 3rem)

Body:
16–20px

Labels:
12–14px uppercase with tracking

## Buttons

Primary:
- white text on WOLVO blue or white fill depending on context
- subtle magnetic hover
- small arrow icon

Secondary:
- transparent
- thin border
- blue hover glow

Do not make every button glowing.

## Cards

Preferred:
- dark translucent surface
- thin blue/navy border
- subtle blur only when useful
- large visual area
- minimal text

## Backgrounds

Use:
- dark navy
- soft radial blue illumination
- subtle grain
- restrained particles

Never use:
- noisy gradient mesh everywhere
- rainbow gradients
- pure black on every section

## Iconography

Use one consistent outline icon family.

Recommended:
Lucide Icons for utility UI.

Main service visuals should be 3D rather than generic icon-only cards.

## Spacing

Prefer generous but purposeful whitespace.

Avoid huge dead space.

## Shapes

Use:
- angular forms
- subtle rounded corners
- asymmetric geometry
- strong alignment

Avoid:
- generic pill-everything designs
